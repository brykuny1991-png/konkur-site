# Конный клуб «Конкур» — сайт

Работа по брифу заказчика (документ Word, структура на 10 страниц).
Основной сайт собирается на **Tilda**. В этом репозитории — демонстрационная
копия главной страницы, свёрстанная отдельно, и рабочие материалы проекта.

**Живая страница:** https://brykuny1991-png.github.io/konkur-site/

---

## Почему копия, а не выгрузка из Tilda

Tilda не отдаёт исходный код сайта на тарифах Free и Personal — экспорт есть
только в тарифе Business. Выложить сюда настоящий Tilda-сайт технически
невозможно. Страница в этом репозитории свёрстана заново, вручную, и повторяет
структуру и содержание того, что собрано в Tilda.

## Что в репозитории

| Файл | Что это |
|---|---|
| `index.html` | Главная страница, один файл, без сборки и зависимостей |
| `TEKSTY-SAYTA.md` | Тексты под все 10 страниц сайта, поблочно |
| `VOPROSY-ZAKAZCHIKU.md` | Список недостающих данных — письмо заказчику |
| `foto/oblozhka-kon.jpg` | Фотография обложки, лицензия CC0 |

## Состояние работы

Готово:

- разбор брифа, структура сайта на 10 страниц;
- тексты под каждый блок каждой страницы;
- главная страница в Tilda — переписаны 12 блоков;
- главная страница здесь — вёрстка с нуля.

Не готово, потому что нет данных от заказчика:

- название клуба, телефон, адрес конюшни;
- фотографии лошадей, тренеров и конюшни;
- количество посещений в тарифе «половина аренды» — в брифе пропущено;
- цены на абонементы занятий и на работу с лошадью;
- содержание страниц «Обучение на тренера» и «База знаний».

Всё незаполненное помечено на странице словом «уточняется», а не заглушками
вроде Lorem ipsum: так видно, чего именно не хватает.

## Технические решения

- Один HTML-файл, никакой сборки. Открывается двойным кликом.
- Шрифты — Google Fonts: Saira Condensed (заголовки), Spectral (текст),
  IBM Plex Mono (цифры и измерения).
- Адаптив от 320 px. Меню на узких экранах скрывается, сетки схлопываются
  в одну колонку.
- Учтён `prefers-reduced-motion` — анимация отключается, если пользователь
  просил уменьшить движение в системе.
- Видимый фокус с клавиатуры на всех интерактивных элементах.
- Формы нет: GitHub Pages — статический хостинг, принимать заявки он не умеет.
  Вместо формы — почта. В рабочем сайте на Tilda форма есть.

## Про фотографию

Снимок взят из Openverse с лицензией **CC0**: коммерческое использование
разрешено, указывать автора не требуется. Лицо всадника не видно — это снимает
вопрос прав на изображение человека. Снимок временный, для живого сайта нужны
фотографии клуба.
